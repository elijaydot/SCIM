BitLocker is a built-in Windows security feature that protects your computer's data by encrypting the hard drive. Encryption means turning your files into a secret code that only authorized users can read.

Real-life example
Imagine your laptop is a locked safe:
    - Your files = valuable items inside the safe.
    - BitLocker = the strong lock on the safe.
    - Recovery Key = the spare key stored in a secure place.

If someone steals your laptop and removes the hard drive, they still cannot read the data because it is encrypted.

How BitLocker works
    1. BitLocker encrypts the drive.
    2. When Windows starts, BitLocker verifies the device.
    3. If everything looks normal, Windows opens normally.
    4. If BitLocker detects suspicious changes (hardware changes, boot tampering, etc.), it may ask for the 48-digit Recovery Key.

Important terms
TPM (Trusted Platform Module)
A small security chip on most modern computers.
Think of it as a security guard that helps BitLocker confirm that nobody has tampered with the computer before Windows starts.

Recovery Key
A unique 48-digit code used to unlock the drive if BitLocker cannot verify the device.

Example:
123456-123456-123456-123456-123456-123456-123456-123456
Always back it up securely.

BitLocker vs Password
Password	                            BitLocker
Protects Windows sign-in	            Protects the entire drive
Can be bypassed by removing the disk	Data remains encrypted even if disk is removed
User authentication	                    Data-at-rest protection

Licensing
BitLocker Drive Encryption is available on:
    Windows Pro
    Windows Enterprise
    Windows Education

Windows Home typically uses the simpler Device Encryption feature when supported by the hardware.

For Microsoft Entra / M365 Admins
BitLocker recovery keys can be stored in:
    Microsoft Entra ID (Azure AD)
    Active Directory
    Microsoft Intune

This allows admins to retrieve recovery keys when users are locked out.

Easy interview answer
    BitLocker is Microsoft's full-disk encryption solution that protects data on Windows devices by encrypting drives. It uses TPM, PINs, startup keys, and recovery keys to prevent unauthorized access if a device is lost, stolen, or tampered with.

As a Technical Support Engineer, the most common BitLocker-related issue you'll encounter is users being prompted for the BitLocker Recovery Key after hardware, BIOS/UEFI, or boot configuration changes.



LAPS - Local Admin Password Solution
ONLY WORKS WITH ENtra Joined Devices and not Entra Registered.

LAPS in Azure (Microsoft Entra ID)
What is LAPS?

LAPS (Local Administrator Password Solution) is a Microsoft feature that automatically creates, stores, and rotates the password of the local Administrator account on Windows devices. Instead of every PC using the same local admin password, each device gets its own unique password.

FURTHER EXPLANATION
Imagine a school has 500 classrooms.

❌ Bad idea:
    - Every classroom uses the same key.
    - If a student steals one key, they can enter every classroom.

✅ Better idea (LAPS):
    - Every classroom gets a different key.
    - The keys change automatically every few weeks.
    - The principal keeps a secure record of all keys.

That's exactly what Windows LAPS does for Windows computers.

Why LAPS is Needed
Without LAPS:
```text
PC1 -> Administrator = Welcome123
PC2 -> Administrator = Welcome123
PC3 -> Administrator = Welcome123
```

An attacker who gets the password from one PC can use it on many others.

With LAPS:
```text
PC1 -> Administrator = X#4tR9!Qm2
PC2 -> Administrator = K@8Lp2$Zv1
PC3 -> Administrator = M!7Qa6#Wk5
```

Each password is unique and periodically changed automatically. This helps prevent Pass-the-Hash (PtH) and lateral movement attacks.

Azure LAPS Architecture
```text
Windows Device
      │
      ▼
Windows LAPS
      │
      ▼
Microsoft Entra ID
      │
      ▼
Password stored securely
      │
      ▼
Authorized Admin retrieves password
```
The device backs up its local administrator password to Microsoft Entra ID, where authorized administrators can retrieve it when needed.

Main Features
1. Automatic Password Rotation
    Passwords change automatically after a configured number of days.

2. Secure Storage
    Passwords are stored securely in Microsoft Entra ID.

3. Password Recovery
    Authorized admins can view the current password if they need to access the machine.

4. Auditing
    Password retrieval and updates can be audited and monitored.

5. RBAC Support
    Access to passwords can be controlled through Role-Based Access Control (RBAC).

How to Enable LAPS in Entra ID
Step 1
Go to:
```text
Microsoft Entra Admin Center
    ↓
Devices
    ↓
Device Settings
    ↓
Enable Local Administrator Password Solution (LAPS)
```

LAPS must first be enabled at the tenant level before devices can back up passwords to Entra ID.

Step 2
Create a Windows LAPS policy using Microsoft Intune. This is the recommended deployment method for Entra-joined devices.

Configure:
    Password length
    Password complexity
    Password age
    Administrator account name
    Post-authentication actions

Step 3
Assign the policy to devices or users.
Once applied:
```text
Device
   ↓
Generates Password
   ↓
Backs up to Entra ID
   ↓
Rotates automatically
```

How an Admin Retrieves the Password

Navigate to:
```text
Microsoft Entra Admin Center
   ↓
Devices
   ↓
All Devices
   ↓
Select Device
   ↓
Local administrator password recovery
```

If you have the appropriate permissions, you'll see the current password and expiration time.

Common Interview Question
Q: What problem does LAPS solve?

Answer:
    Windows LAPS protects local administrator accounts by automatically generating unique passwords for each device, securely backing them up to Microsoft Entra ID or Active Directory, and rotating them regularly. This reduces the risk of Pass-the-Hash and lateral movement attacks.

LAPS vs PIM

| Feature                           | LAPS| PIM| 
|------------------------------     |----------| 
| Protects Local Admin Account      | ✅ | ❌ | 
| Rotates Passwords                 | ✅ | ❌ | 
| Just-in-Time Access               | ❌ | ✅ | 
| Manages Entra Roles               | ❌ | ✅ | 
| Stores Local Admin Passwords      | ✅ | ❌ |

PIM secures privileged identities, while LAPS secures local administrator passwords on Windows devices. They complement each other rather than replace one another.
