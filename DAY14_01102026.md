Password Hash Synchronization (PHS) vs Pass-Through Authentication (PTA)

Think of both as ways for Microsoft Entra ID (Azure AD) to verify a user's password when your organization has an on-premises Active Directory and Entra ID working together.

Simple Explanation
Imagine your school has a paper attendance book (on-prem AD) and a digital attendance app (Entra ID).

Password Hash Synchronization (PHS)
The school copies a safe, scrambled version of every student's password into the cloud.

When Elijah signs in:
    1. Entra ID checks the scrambled password copy stored in the cloud.
    2. No need to ask the school's server.
    3. Sign-in is fast and keeps working even if the school server is offline.

Key point: Authentication happens in the cloud.

Pass-Through Authentication (PTA)
The cloud does not keep a password hash copy for authentication.

When Elijah signs in:
    - Entra ID receives the login request.
    - It sends the authentication request to a PTA Agent on-premises.
    - The PTA Agent asks the Domain Controller if the password is correct.
    - The result is returned to Entra ID.

Key point: Authentication happens against your on-prem Active Directory every time.

Authentication Flow
PHS
```text
User
  |
  v
Microsoft Entra ID
  |
  v
Password verified in the cloud
```

PTA
```text
User
  |
  v
Microsoft Entra ID
  |
  v
PTA Agent (On-Prem)
  |
  v
Domain Controller
```

Quick Comparison
Feature	                                    Password Hash Sync (PHS)	                    Pass-Through Authentication (PTA)
Authentication Location	                    Cloud (Entra ID)	                            On-prem AD
Requires On-Prem During Login	            No	                                            Yes
Works if Domain Controllers are down	    Yes (after sync)	                            No
Infrastructure	Simpler	Requires PTA Agents
Performance	Faster	Slightly dependent on on-prem connectivity
Microsoft Recommendation	Generally preferred	Used for specific requirements
Which One Should You Choose?
Choose PHS if:

✅ You want the simplest deployment
 ✅ You want better resilience/disaster recovery
 ✅ You want users to still sign in if on-prem infrastructure fails
 ✅ You're moving toward cloud-first identity

Microsoft generally recommends PHS as the simplest and most resilient option.

Choose PTA if:

✅ Your organization requires password validation against on-prem AD every login
 ✅ Compliance or security policies do not allow cloud password-hash synchronization
 ✅ You still want cloud sign-in without deploying AD FS

Exam Tip (AZ-104 / SC-300)

Remember this:

PHS = Password hash is synced to Entra ID, and Entra ID authenticates the user.

PTA = Password is checked against the on-prem Domain Controller for every sign-in.

That's the easiest way to quickly identify the correct answer in certification exams. ✅
